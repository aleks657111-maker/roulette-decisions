# CLAUDE.md

Этот файл содержит указания для Claude Code (claude.ai/code) при работе с кодом в этом репозитории.

## Проект

«Рулетка решений» — статичное веб-приложение без сборки и зависимостей: колесо, которое случайно выбирает пункт из фиксированного списка. Три файла: [index.html](index.html), [script.js](script.js), [style.css](style.css). Нет package.json, сборщика или тестового фреймворка.

## Запуск / проверка изменений

Открой [index.html](index.html) прямо в браузере, либо запусти в папке любой статичный сервер (например, `npx serve .`). Шаг сборки отсутствует — правки в `script.js`/`style.css` применяются сразу после перезагрузки страницы.

Сброс кэша: `index.html` подключает `style.css?v=N` и `script.js?v=N`. Увеличивай параметр `v=` при каждом изменении `style.css` или `script.js`, чтобы браузер не отдавал устаревшую закэшированную версию.

## Архитектура

- Вся логика колеса находится в одном IIFE в [script.js](script.js). Состояние (`items`, `rotation`, `spinning`, `highlightIndex`) хранится в области видимости модуля, без какого-либо фреймворка.
- Список пунктов (массив `items`, script.js:19) захардкожен прямо в коде — интерфейса для добавления/редактирования/удаления пунктов пользователем нет (это было намеренно убрано, см. историю коммитов).
- Отрисовка колеса (`drawWheel`) рисует секторы на `<canvas>` через 2D-контекст, с учётом `devicePixelRatio` (script.js:2-10). Цвета секторов вычисляются по HSL-оттенку, равномерно распределённому по количеству пунктов (`hueFor`/`colorFor`), а не хранятся отдельно для каждого пункта.
- Вращение реализовано через CSS `transform: rotate()` с transition на элементе canvas (а не через цикл перерисовки canvas): `spin()` вычисляет целевой угол поворота так, чтобы указатель, зафиксированный на 270°, указывал на случайно выбранный выигрышный сектор, добавляет несколько полных оборотов для эффектности и слушает событие `transitionend`, чтобы зафиксировать результат.
- Показ результата (`showResult`) и залп конфетти (`launchConfetti`) запускаются по `transitionend`; частицы конфетти — это `<span>`-элементы, анимируемые через инлайновые CSS custom properties (`--fall-distance`, `--drift`, `--spin`), которые используются в CSS-анимациях в `style.css`.
- `skills-lock.json` в корне репозитория не относится к самому приложению колеса (это lock-файл инструментария) — не путай его с состоянием приложения.

## Заметки из истории изменений

- Колесо намеренно зафиксировано в размере 330px и недоступно для редактирования пользователем (см. коммит `731d245`) — не возвращай интерфейс «добавить/удалить пункт», если явно не попросят.
- Внешняя обводка колеса была намеренно возвращена с радужного кольца обратно на простой тёмный контур (коммит `7178b55`) — сохраняй так, если не попросят изменить.
